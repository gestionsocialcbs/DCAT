# Capacitación y Adiestramiento Técnico 2019–2026

Tablero de análisis de inscripciones y asistencias de Capacitación y Adiestramiento Técnico (IMSS · Prestaciones Sociales · DATMP).

## Publicación en GitHub Pages

1. Suba `index.html` y `Equipo_de_Computo_CBS.pdf` a la raíz del repositorio.
2. En el repositorio: **Settings → Pages → Build and deployment**, elija **Deploy from a branch**, rama `main`, carpeta `/ (root)` y guarde.
3. El tablero quedará disponible en `https://<usuario>.github.io/<repositorio>/`.

El archivo es autónomo: incluye los datos (comprimidos), las imágenes, los planos y la tipografía. Solo requiere conexión para cargar la biblioteca de gráficas D3 desde cdnjs.
